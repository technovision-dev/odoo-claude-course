# Changelog

## 18.0.1.0.0 - 2026-09-25

### Added
- Follow-up levels with an email template and an optional To-Do for the salesperson.
- Daily scheduled action: the highest level reached only, each level once per quotation.
- Skips: customer opt-out (contact or company), expired quotations, customer replies,
  follow-ups turned off for the company.
- Follow-up log, a smart button on the quotation, and "Send follow-up now".
- Two email templates.
